# Distribution

Recommended channels:

1. Steam Workshop for player discovery, subscription, and updates.
2. GitHub for source, issues, and versioned ZIP downloads through Releases.

Mega Crit officially enabled STS2 Workshop support in its [June 2026 announcement](https://megacrit.com/news/2026-6-19-neowsletter-issue-23/). A community mod listed there is not an official Mega Crit-authored or endorsed mod.

The [official uploader](https://github.com/megacrit/sts2-mod-uploader) creates a workspace containing content, workshop.json, and image.png. Copy only this mod's DLL and JSON to content, fill out the listing, provide an image below 1 MB, then use the documented upload command. Keep its generated mod_id.txt so future uploads update the same listing. Do not upload installer files, the GameProbe test mod, game files, or synthetic profiles.

Before public Workshop release, complete a real Steam friend-session playtest and review the title, description, compatibility statement, and preview image. Start with a limited-visibility listing if the uploader supports it. Native Workshop subscriptions should replace the manual copy, not coexist with it.

GitHub release notes are in release-0.1.1.md. Attach dist/RandomCharacterBlacklist-0.1.1.zip to the matching release. GitHub's automatically generated source archives are not the installable mod.
