# Random Character Options 0.1.1 — preview

Built by Rodney Wells (WatersEdge) with GPT-6 Astra.

For Slay the Spire 2 **v0.111.0 on Windows**.

Download **RandomCharacterBlacklist-0.1.1.zip** below, extract the whole ZIP, close STS2, and run **Install.cmd**. The source-code archives are for developers, not installation. No BaseLib, SDK, or separate mod loader is required. The internal filename preserves compatibility with early-preview settings.

- Choose which characters are included in Random; all start enabled.
- Every Random activation rerolls. Turn Custom Random off to restore native behavior.
- Open the dice icon or press F8. Character icons, colors, and interruptible death/power previews accompany the options.
- Preferences affect only your own choices. Normal game unlock rules still apply.

Release build and core/installer checks passed. Instrumented local multiplayer tests passed with both-installed, host-only, and client-only setups through run initialization. A real Steam friend session and full combat run remain untested. See packaging/VALIDATION.md in the repository for details.

This is a community mod, not a Mega Crit product. No Workshop listing exists yet. If switching to Workshop later, remove the manual installation to avoid duplicate copies.
